# 묵독 (默讀)

조용히, 한 페이지씩 읽는 오프라인 독서 앱입니다. 소리 내지 않고 읽는다는 뜻의 '묵독'에서 이름을 가져왔습니다.

## 화면 구성

- **초기 화면**: 이름과 일러스트, 진입 버튼 세 개만 보입니다. 읽은 책이나 권수 같은 개인 정보는 표시하지 않습니다.
- **서재**: 책 목록과 필터(전체·읽는 중·완독)가 있습니다. 왼쪽 위 버튼으로 초기 화면에 돌아갑니다.
- **읽기**: 메뉴 아이콘은 자동으로 숨고, 화면을 한 번 누르면 나타납니다.

## 파일 구성

```
index.html              화면 구조 (초기 화면 / 서재 / 읽기 / 설정)
styles.css              디자인 (한지·먹·쪽빛 팔레트, 세 가지 화면 테마)
app.js                  파서, 서재 저장, 목차 인식, 이어 읽기, 시스템 TTS
sw.js                   서비스 워커 (오프라인 동작)
manifest.json           홈 화면 설치 정보
apple-touch-icon-v2.png 아이콘 원본 (180×180, 참고용)
icons/                  안드로이드·PWA 아이콘
```

아이폰 홈 화면 아이콘은 `index.html` 안에 직접 들어 있습니다. 파일 주소를 읽지 않으므로 경로 문제의 영향을 받지 않습니다.

## 1. GitHub에 올리기

1. 새 저장소를 만듭니다. GitHub Pages를 무료로 쓰려면 Public이어야 해요.
2. zip을 풀어 안의 파일을 **저장소 최상위에** 올립니다. `icons` 폴더도 함께 올라가야 합니다.
3. Settings › Pages에서 Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 선택합니다.

## 2. 아이폰 홈 화면에 설치

1. **Safari**로 주소를 엽니다. (Chrome에서는 설치가 안 돼요.)
2. 인터넷에 연결된 상태에서 한 번 열고 몇 초 기다려 주세요. 앱 파일과 글꼴이 기기에 저장됩니다.
3. 공유 버튼 › **홈 화면에 추가**를 누릅니다. 이름이 '묵독'으로 나와야 합니다.

## 3. 아이콘이 여전히 기본 글자 타일로 나온다면

1. 홈 화면의 기존 '서재' 앱을 길게 눌러 삭제합니다.
2. 설정 › Safari › 고급 › 웹사이트 데이터에서 `github.io`를 검색해 삭제합니다. 다른 github.io 사이트의 데이터도 함께 지워지니 참고해 주세요.
3. Safari에서 주소를 다시 열고 공유 › 홈 화면에 추가를 누릅니다.
4. 그래도 같은 타일이 나오면 iOS 버전과 함께 알려 주세요.

> 주의: 홈 화면 앱을 삭제하면 그 앱 안에 저장된 책과 읽기 위치가 지워질 수 있습니다. 중요한 책은 원본 파일을 먼저 보관해 주세요.

## 4. 업데이트하는 법

`sw.js`의 `CACHE` 값을 올린 뒤 다시 올립니다. 예: `seoga-reader-v1.3.1`. 홈 화면 앱은 완전히 닫았다가 다시 열어 주세요.

## 5. 알아 두실 점

- **앱 전환 화면**: 다른 앱으로 넘어갈 때 본문이 흐리게 보이도록 처리했습니다. 다만 iOS가 전환 화면을 만드는 시점에 따라 완벽하지 않을 수 있어요.
- **글꼴**: 고딕은 Pretendard, 명조는 Gowun Batang을 씁니다. 처음 한 번 온라인에서 열면 저장되고, 이후에는 오프라인에서도 쓸 수 있습니다.
- **데이터 위치**: 책과 읽기 위치는 그 기기 안에만 저장됩니다. 기기끼리 동기화되지 않아요.
- **스캔본 PDF**: 글자 정보가 없는 스캔 PDF는 지원하지 않아요.
